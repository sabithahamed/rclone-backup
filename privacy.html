Privacy policy

This application is a private, single-user configuration of rclone, an open-source file transfer tool. It is operated by its owner for their own personal use only.

What it does

It copies the owner's own files between storage accounts that belong to the owner. It has no other users, no sign-up, and offers no public service.

Data it accesses

Google Drive access is limited to the drive.file scope, which allows the application to see and manage only the files it creates itself. It cannot read any other file in the account.

Data it collects or shares

None. No personal information is collected, stored on any server operated by this application, or shared with any third party. Files are transferred directly between the owner's own accounts.

Revoking access

Access can be withdrawn at any time from the Google Account permissions page at myaccount.google.com/permissions.

Contact

Use the support email shown on the Google consent screen.
